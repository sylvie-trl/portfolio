# Portfolio – Sylvie Trollé

Portfolio personnel développé avec React afin de présenter mon profil, mes compétences et plusieurs projets réalisés dans le cadre de ma formation en développement web.

## Aperçu

Ce portfolio met en avant :

- mon parcours et mes compétences
- plusieurs projets réalisés (front-end et back-end)
- les technologies utilisées
- les liens vers les dépôts GitHub et les démonstrations

Le site a été conçu comme une application React simple et accessible, avec une attention particulière portée à la clarté de l’interface et à la structure du code.

## Technologies utilisées

- React
- JavaScript (ES6)
- HTML5
- CSS3 (CSS Modules)
- Vite

## Installation

### Cloner le projet :

```bash
git clone https://github.com/sylvie-trl/portfolio.git
```

### Installer les dépendances :

```bash
npm install
```

### Lancer le serveur de développement :

```bash
npm run dev
```

### Le site sera accessible à l'adresse :

```
http://localhost:5173
```
